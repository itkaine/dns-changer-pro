# DNS Changer Pro cho Windows

[English](README.md) | **Tiếng Việt**

Ứng dụng đổi DNS nhanh, giao diện hiện đại cho Windows 10 / 11. Hỗ trợ đầy đủ IPv4 & IPv6, kiểm tra tốc độ DNS thật, khôi phục DHCP và Flush DNS chỉ với 1 click.

## 📥 Tải về

👉 **[Tải bản mới nhất](https://github.com/itkaine/dns-changer-pro/releases/latest)**. Chọn file `DNS.Changer.Pro.Setup.x.y.z.exe` ở mục **Assets**.

Tất cả phiên bản: [Releases](https://github.com/itkaine/dns-changer-pro/releases)

## 🚀 Tính năng

- **IPv4 & IPv6**: đổi một hoặc cả hai giao thức cùng lúc.
- **DNS dựng sẵn**: Cloudflare (Standard / Security / Family), Google Public DNS, Quad9, OpenDNS & FamilyShield, AdGuard (Default / Family), NextDNS, Control D, DNS.WATCH.
- **DNS nhà mạng Việt Nam**: Viettel, VNPT, FPT. Chỉ hoạt động khi bạn đang dùng mạng của chính nhà mạng đó.
- **DNS tuỳ chỉnh**, có kiểm tra định dạng địa chỉ.
- **Kiểm tra tốc độ DNS**: gửi truy vấn DNS thật tới từng máy chủ và hiển thị thời gian phản hồi (ms).
- **Khôi phục DHCP**: trở về DNS tự động của router / nhà mạng chỉ với 1 click.
- **Flush DNS**: xoá bộ nhớ đệm DNS của Windows.
- **Tự nhận diện card mạng** (Ethernet, Wi-Fi).
- **Giao diện English / Tiếng Việt**: chuyển bằng nút `EN | VI` trên thanh tiêu đề.

## 💻 Cài đặt

1. Tải file `DNS.Changer.Pro.Setup.x.y.z.exe` tại [Releases](https://github.com/itkaine/dns-changer-pro/releases/latest).
2. Click đúp và chọn **Yes** ở hộp thoại UAC. Đổi DNS cần quyền Administrator.
3. Ứng dụng được cài vào `C:\Program Files\DNS Changer Pro` và tạo shortcut ở Desktop / Start Menu.

> Nếu Windows SmartScreen báo "Windows protected your PC", bấm **More info → Run anyway**.

**Yêu cầu:** Windows 10 / 11 (64-bit).

## ❓ Câu hỏi thường gặp

- **DNS Viettel / VNPT / FPT báo "Timeout"?** DNS nhà mạng VN chỉ phản hồi thuê bao của chính nhà mạng đó. Chỉ dùng khi bạn đang ở mạng của nhà mạng đó.
- **Muốn trả lại như cũ?** Bấm **Khôi phục DHCP** để về DNS tự động.
- **Nâng cấp từ v1.0.3 trở về trước?** Sau khi cài bản mới, vào **Settings → Apps → Installed apps**. Nếu thấy 2 mục "DNS Changer Pro" thì gỡ mục cũ.
