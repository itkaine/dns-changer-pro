# DNS Changer Pro for Windows

**English** | [Tiếng Việt](README.vi.md)

A fast, modern DNS switcher for Windows 10 / 11, with full IPv4 & IPv6 support, a real DNS speed test, one-click DHCP restore and Flush DNS.

## 📥 Download

👉 **[Download the latest version](https://github.com/itkaine/dns-changer-pro/releases/latest)**. Pick the file `DNS.Changer.Pro.Setup.x.y.z.exe` under **Assets**.

All versions: [Releases](https://github.com/itkaine/dns-changer-pro/releases)

## 🚀 Features

- **IPv4 & IPv6**: change one or both protocols at once.
- **Built-in DNS providers**: Cloudflare (Standard / Security / Family), Google Public DNS, Quad9, OpenDNS & FamilyShield, AdGuard (Default / Family), NextDNS, Control D, DNS.WATCH.
- **Vietnamese ISP DNS**: Viettel, VNPT, FPT. These only answer while you are on that ISP's own network.
- **Custom DNS** with address validation.
- **DNS speed test**: sends a real DNS query to every server and shows the response time (ms).
- **Restore DHCP**: go back to automatic DNS from your router / ISP in one click.
- **Flush DNS**: clears the Windows DNS cache.
- **Automatic network adapter detection** (Ethernet, Wi-Fi).
- **English / Tiếng Việt UI**: switch with the `EN | VI` toggle in the titlebar.

## 💻 Installation

1. Download `DNS.Changer.Pro.Setup.x.y.z.exe` from [Releases](https://github.com/itkaine/dns-changer-pro/releases/latest).
2. Double-click it and choose **Yes** at the UAC prompt. Changing DNS requires Administrator rights.
3. The app installs to `C:\Program Files\DNS Changer Pro` and adds Desktop / Start Menu shortcuts.

> If Windows SmartScreen shows "Windows protected your PC", click **More info → Run anyway**.

**Requirements:** Windows 10 / 11 (64-bit).

## ❓ FAQ

- **The Viettel / VNPT / FPT DNS shows "Timeout"?** Vietnamese ISP DNS servers only answer subscribers of that ISP. Use them only on that ISP's network.
- **How do I undo the change?** Click **Restore DHCP** to return to automatic DNS.
- **Upgrading from v1.0.3 or older?** After installing the new version, check **Settings → Apps → Installed apps**. If "DNS Changer Pro" appears twice, uninstall the older entry.
